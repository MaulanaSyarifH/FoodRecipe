# Foodie — Food Recipes App (Coursera Final Project)

React Native + Expo app for the peer-graded assignment.

## Run with Expo Go
1. Clone this repo
2. `npm install`
3. `npm start`
4. Scan QR with Expo Go

## Import in Snack Expo
Use **Import Git Repository** with:
https://github.com/MaulanaSyarifH/FoodRecipe

(`package.json` is at the **repo root** so Snack can import directly.)

## Quick test flow
Welcome → Home (categories + recipes) → Recipe detail (♥ favorite) → My Favorites → My Food → Add New recipe
